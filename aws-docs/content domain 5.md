

# Content Domain 5: Incident and Event Response
<a name="devops-engineer-professional-02-domain5"></a>

## Task Statement 5.1: Manage event sources to process, notify, and take action in response to events.
<a name="dop-02-task-5-1"></a>

### Knowledge of:
<a name="dop-02-task-5-1-knowledge"></a>
+ AWS services that generate, capture, and process events (for example, AWS Health, Amazon EventBridge, AWS CloudTrail)
+ Event-driven architectures (for example, fan out, event streaming, queuing)

### Skills in:
<a name="dop-02-task-5-1-skills"></a>
+ Integrating AWS event sources (for example, AWS Health, EventBridge, CloudTrail)
+ Building event processing workflows (for example, Amazon SQS, Amazon Kinesis, Amazon SNS, AWS Lambda, AWS Step Functions)

## Task Statement 5.2: Implement configuration changes in response to events.
<a name="dop-02-task-5-2"></a>

### Knowledge of:
<a name="dop-02-task-5-2-knowledge"></a>
+ Fleet management services (for example, AWS Systems Manager, AWS Auto Scaling)
+ Configuration management services (for example, AWS Config)

### Skills in:
<a name="dop-02-task-5-2-skills"></a>
+ Applying configuration changes to systems
+ Modifying infrastructure configurations in response to events
+ Remediating a non-desired system state

## Task Statement 5.3: Troubleshoot system and application failures.
<a name="dop-02-task-5-3"></a>

### Knowledge of:
<a name="dop-02-task-5-3-knowledge"></a>
+ AWS metrics and logging services (for example, Amazon CloudWatch, AWS X-Ray)
+ AWS service health services (for example, AWS Health, CloudWatch, Systems Manager OpsCenter)
+ Root cause analysis

### Skills in:
<a name="dop-02-task-5-3-skills"></a>
+ Analyzing failed deployments (for example, AWS CodePipeline, AWS CodeBuild, AWS CodeDeploy, AWS CloudFormation, CloudWatch synthetic monitoring)
+ Analyzing incidents regarding failed processes (for example, auto scaling, Amazon ECS, Amazon EKS)
